## Design direction

Deep Ocean Intelligence: midnight `#071826`, deep blue `#102940`, aqua `#12C6C8`, seafoam `#68DDC6`, mist `#EAF7F6`, amber `#FFB65C`. Accessible dark/light text pairs refine these colors. Sora is the display face; existing Inter is retained for reading, controls and scientific numerals. Both are hosted locally with their OFL licenses.

Landing is an asymmetric observation sheet: left-aligned editorial headline, illustrated contour field and a dated real observation panel, followed by method, measured evidence, contrasting historical outcomes and limitations. Illustration is explicitly not bathymetric measurement or a sensor network.

```text
Brand / platform / method / performance / theme / account
Promise + two useful links  |  contours + actual dated observation
Observe → Analyze → Forecast → Explain
Daily source / freshness   |  product capabilities
Versioned performance     |  successful + unsuccessful replay
Method / limitations / notifications / FAQ / source footer
```

The application keeps its existing route contracts, authentication, modals and data controls. Shared ocean surfaces, readable chart labels, restrained status colors, consistent 44 px controls and visible keyboard focus connect every page. The most expressive element is the landing contour field; operational screens stay quiet and readable. No invented graphs, customers or performance percentages. Motion follows user actions and respects reduced motion.

Skill search returned a generic enterprise sales gateway; that conversion pattern and its palette/type recommendations do not fit this brief and are not adopted. The useful dashboard density, filtering, contrast and keyboard guidance is applied alongside the owner's explicit ocean direction.
